Desde aquí decides qué juegos aparecen en Explorar y qué versiones recomienda el instalador. Cada cambio se guarda como un commit en Coronitaa/Coronitaa.github.io: solo una cuenta con permiso de escritura en ese repo puede publicar.

También puedes importar un archivo .json con el token (clave Admin): se lee en el navegador y no se muestra.

Crea un token fine-grained con acceso solo al repo Coronitaa.github.io, permiso Contents: Read and write y caducidad corta. Se guarda solo en esta pestaña y se borra al cerrarla.
